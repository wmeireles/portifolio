# Portfólio Profissional

Um portfólio moderno e responsivo desenvolvido com React e Bootstrap para destacar projetos e habilidades profissionais.

## Características

- Design moderno e profissional com tema escuro
- Layout totalmente responsivo para todos os dispositivos
- Seções organizadas para projetos de Backend, Frontend, Mobile e UX/UI
- Animações suaves e interações para melhorar a experiência do usuário
- Formulário de contato funcional
- Otimizado para SEO e performance

## Tecnologias Utilizadas

- React.js
- React Bootstrap
- React Router
- React Icons
- CSS3 com variáveis e animações
- Componentes reutilizáveis

## Instalação e Execução

1. Clone o repositório:
```
git clone https://github.com/seu-usuario/portfolio.git
```

2. Instale as dependências:
```
cd portfolio
npm install
```

3. Execute o projeto em modo de desenvolvimento:
```
npm start
```

4. Para build de produção:
```
npm run build
```

## Personalização

- Edite os dados dos projetos em `src/data/projects.js`
- Modifique as informações pessoais nas páginas em `src/pages/`
- Ajuste as cores e estilos em `src/index.css` (variáveis CSS)
- Substitua as imagens em `src/assets/`
